# Phase 5 3台運用の確認

2026年11月20日：3台分の設定雛形、先生用管理画面、模擬エージェント、3台の独立動作試験を追加。
2026年11月21日に利用者から単機での実行確認完了の報告を受けた。
Phase 5は実装・模擬検証済み、単機での実機確認済み。2・3台目は製作待ちのため、複数機での実機確認は保留。
実機3台に別プログラムを割り当てる確認は未実施。模擬試験の成功を実機3台の完了とはしない。

## 個体ごとの準備

config/local.example.jsonにはrobot-01〜03を記載した。既存config/local.jsonへ雛形を上書きしない。
必要な個体だけ追記し、ID・個体token・表示名を別々にする。tokenは32文字以上のランダムな値とする。
共通ファームウェアを使い、各機体のrobot_config.hのROBOT_ID・ROBOT_TOKENをその個体へ合わせる。
走行方向・1マス・90度の時間は各個体のcalibrationで調整する。設定変更はサーバー再起動で反映する。
雛形はmotionEnabled=false。走行確認後に個体ごとに有効にする。現在の機体の調整値は変更しない。

最初は車輪を浮かせ、1台ずつ前進・後退・左右・停止を確認する。配線の変更は両方の電源を切って行う。
3台ともprotocolVersion=2で接続し、GET /api/robotsのavailable=trueとなることを確認する。

## 機体の状態画面

管理パネルの「機体の状態」では、設定された全機体の接続・実行状態を1秒ごとに更新する。
個別の停止要求、全進行中実行への停止要求を行える。参加者管理・個人別履歴・進捗管理は行わない。
「すべての機体に停止要求」は現在の実行へSTOPを送り、機体の終端報告を待つ。
将来の実行をロックする非常停止ではない。通信できない場合は物理電源スイッチを使う。

## 実機の完了確認

1. 実行端末の「管理 → 接続設定」でstationTokenを設定する。参加者セッションの発行は不要。
2. 前進1、前進と左旋回、WAITとREPEATなど、見分けられる別の指示を順に作る。
3. 2つの端末で同じ機体へ同時送信しても、1件だけ受け付けることを確認する。
4. それぞれの指示ができた後でA・B・Cを選んで送り、3台へ異なる内容が届くことを確認する。
5. Aだけを停止し、B・Cが継続することを確認する。停止報告後にだけAを再利用できる。
6. Aの通信を断ち、機体が停止し、OFFLINEでも占有が残ることを確認する。B・Cの通信は継続する。
7. サーバー再起動で進行中実行がSTOP_REQUESTEDとなり、各機体の停止報告ごとに占有が解放されることを確認する。
8. ページを再読込しても自動再走行せず、作成中の下書きが復元されることを確認する。

## 実機を使わない模擬3台

実際の機体ID・token・DBとは分離した検証専用設定を使う。以下はルートから実行する。
模擬tokenは公開テスト値なので、実機や教室の設定へ転用しない。

ターミナル1：

```sh
WORKSHOP_CONFIG="$PWD/config/simulation.example.json" \
WORKSHOP_DB=/private/tmp/blockly-simulation.sqlite3 \
apps/server/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8003
```

ターミナル2：

```sh
python3 scripts/simulate_robots.py
```

ビルド済みなら `http://127.0.0.1:8003/` が画面。未ビルドならPhase 4の手順でビルドして検証サーバーを再起動する。
接続設定にはconfig/simulation.example.jsonのstationTokenを入力する。
表示名とファームウェアには「模擬」「SIMULATION-no-motors」が表示される。実機は駆動しない。

Viteを使う場合は `ROBOT_API_URL=http://127.0.0.1:8003 npm run dev --prefix apps/web` とし、5173番を開く。
模擬プロセスを終了するとOFFLINEになる。1台だけの通信断を試す場合は、3つのターミナルで
`python3 scripts/simulate_robots.py --robot sim-robot-01` のように1台ずつ起動する。
模擬機体の消費済み番号はメモリ上のみで、実機NVSの試験の代替にはならない。
検証を終えたら模擬サーバーとエージェントをCtrl+Cで終了する。実機用の8000番やDBには接続しない。
